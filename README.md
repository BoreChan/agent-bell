# Agent Bell

Codex 任务完成后，键盘和鼠标连续 10 秒没有活动时显示全屏提醒，按键或操作鼠标即可收起。托盘支持预览提醒、开机启动和退出。

我平时用 iPad 上的 VoidLink 远程办公。切到抖音刷视频时，我会把远程桌面留在画中画里。小窗里一出现全屏提醒，瞄一眼就知道 Codex 的任务做完了。

**运行要求**　Windows x64 · .NET Framework 4.7.2
